# v0.3.1

## 変更内容
- Homebrew（`brew install HR0101/tap/attendance`）で 1 コマンド導入できる Formula 構成（`Formula/attendance.rb`・`scripts/generate_homebrew_formula.py`）を追加しました。
- Homebrew 管理時（`ATTENDANCE_MANAGED_BY=homebrew`）はコード（Cellar）と利用者の設定・データ領域を分離し、既定で `~/AttendanceSystem`（または環境変数 `ATTENDANCE_HOME` の指定先）へ `config.json`・`schedule.json`・`logs/`・`browser_data/`・`start.command` を配置するようにしました。
- Homebrew 管理時の更新案内および更新コマンド実行時は、Cellar を直接書き換えず `brew upgrade attendance` を案内するようにしました。
- リリースワークフローでタグ向け `attendance.rb` を生成・添付・`homebrew-tap` へ任意同期する仕組みを追加しました。

## 利用者の操作
- 既存の `git clone` / GitHub ダウンロード版をご利用の場合は、これまでどおり自動更新または `./att update` を利用できます。
- Homebrew で導入する場合は `brew install HR0101/tap/attendance` で導入し、更新時は `brew upgrade attendance` を実行してください（`ATTENDANCE_HOME` を使う場合は起動前に環境変数を設定します）。
