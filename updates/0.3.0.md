# v0.3.0

## 変更内容

- CLIにユーザー削除（`att user remove`）と学籍番号変更（`att user student-id`）を追加しました。削除の確認、Keychainの削除・引き継ぎにも対応します。
- 一括出席の確認画面で全員の名前・学籍番号・登録対象／対象外の理由を表示し、人数が多い場合はスクロールして確認できます。複数ユーザーの処理では認証を分離したままChromiumを共有します。
- 既定ユーザーの切り替え前に、出席対象・保存済み選択・自動実行への影響を表示します。確認画面の初期選択はキャンセルです。
- 自動実行の開始前に既定ユーザー・次回予定・適用期間を表示し、確認中に条件が変わった場合は再確認します。有効な予定がない場合や期間終了後は開始しません。
- 予定の受付時間の重複を検出し、並行操作による設定の上書きを共通ロックで防ぎます。直前の予定変更を1段階取り消す機能を追加し、外部で追加された授業も保持します。
- 自動実行は時刻の分境界に2分の猶予を設け、実行中の排他予約と完了記録で重複を防ぎます。確認のみ・送信前の失敗・未履修・受付対象なしの場合は枠を消費せず、修正後に再試行できます。
- LaunchAgentの起動前エラーをログに記録し、登録失敗時は以前の設定の復元を試みます。`att schedule status` で設定ずれや必要な設定を診断できます。
- メイン画面・予定画面の `L` キーで出席・LaunchAgent・更新ログを閲覧できます。ログは権限とサイズを制限し、エラー理由や並列処理の匿名番号を記録します。
- 予定削除の確認をキャンセル初期選択にし、ユーザー管理の戻り先と失敗時の入力保持を改善しました。入力エラーは最初の不正項目にフォーカスを移します。
- フォームの途中から `Ctrl+S` で保存でき、`F2` または `Ctrl+T` でパスワード表示を切り替えられます。出席処理中は `Esc`・`Q`・`Ctrl+C` で安全な位置での中断を要求できます。
- 全角の教室番号や7号館の4桁番号に対応し、`start.command` は画面モードで起動します。CLIの入力中断や導入・設定不備の案内も改善しました。
- 明るい背景用の配色とモノクロ表示を追加しました。エラー・注意・更新・完了は文字の接頭辞と太字でも判別できます。
- 更新・初回導入・CIでハッシュ検証付きのwheelのみを導入し、古い仮想環境や不要な更新待機データを整理します。更新ZIPからの導入でも同梱情報を検証してロックファイルを復元できます。
- 更新情報とZIPのECDSA P-256署名・検証、およびリリースのビルド由来証明に対応しました。Playwrightの取得元上書きを除外し、Chromiumの実体とリビジョンを検証します。
- 設定・ログのシンボリックリンクを拒否し、ファイル権限を制限します。初回登録はKeychainへの保存確認後に設定を保存し、UIのパスワードは300秒で期限切れにして終了・切り替え時に消去します。
- 不正な遷移先ポートを拒否し、大学側のエラー表示を安全に分類します。macOSのCI、依存ロック同期検証、シークレット検査を追加しました。

## 利用者の操作

- 更新内容は `att update --notes`、適用は `att update` で確認・実行してください。通常起動では更新の通知のみを表示します。
- 自動実行を利用中の場合は、更新後に `att schedule install`（または予定画面の `I` で停止→確認して開始）を実行して最新のログ設定を反映してください。状態の確認は `att schedule status` です。
- 出席登録、既定ユーザー変更、自動実行開始、予定削除の確認画面では、内容を確認して `Tab`／`←→` で実行する選択肢へ移動し、`Enter` で確定してください。初期選択はキャンセルです。
- 一括出席の対象者一覧は `↑↓`／`PgUp`／`PgDn` で移動できます。フォームは `Ctrl+S` で保存、パスワードは `F2`／`Ctrl+T` で表示切り替え、処理中は `Esc`／`Q`／`Ctrl+C` で中断できます。
- 誤って確定した予定変更は一覧の `Z`／`Ctrl+Z` で1段階取り消せます。外部変更が検出された場合は `R` で再読み込みしてください。ユーザー削除やパスワード変更は取り消しの対象外です。
- ログは `L` で開き、`Tab`／`1`～`3` で切り替え、`Esc`／`Q` で戻れます。共有する場合は個人情報を含めないでください。
- 明るい背景で見づらい場合は `ATTENDANCE_UI_THEME=light att --ui`、モノクロ表示は `NO_COLOR=1 att --ui` を使えます。
- 設定の学籍番号は半角英数字で指定してください。受付時間の重複エラーが出た場合は表示された授業と時間を確認して調整してください。
- 暗号署名の必須検証は、配布者が公開鍵を固定した版で有効です。署名なしの既存配布版からも更新できます。
