# v0.2.7

## 変更内容

- ユーザー選択・既定ユーザー変更・ユーザー情報・予定編集で、未保存のまま戻る時に保存確認を表示します。
- 「保存して戻る」「保存せず戻る」「編集を続ける」を選べます。変更がない場合は、そのまま戻れます。
- 保存を選んだ場合は途中の入力項目からでも全体を検証して保存します。入力エラーや保存失敗では内容とカーソル位置を保持し、編集へ戻します。パスワードは再び非表示にします。
- ユーザー情報の子画面から戻った時も、一覧で未確定のユーザー選択を維持します。

## 利用者の操作

- `att update` で更新して画面を開き直してください。
- 入力・選択を変更した後にEscで戻ろうとすると確認が出ます。一覧や確認画面ではQでも戻れます。入力欄のq/Qは文字入力として使えます。
- ↑↓またはTabで選択し、Enterで決定してください。初期選択は「編集を続ける」です。確認中のEsc/Qも編集へ戻ります。
- 保存せずに変更を取り消す時は「保存せず戻る」を明示的に選んでください。デモでは保存を選んでも実際の設定・Keychainは変更しません。
