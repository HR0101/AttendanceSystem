# v0.2.4

## 変更内容

- ユーザー管理画面に、登録ユーザーの削除と学籍番号の変更を追加しました。
- 削除時は対象ユーザーを確認する画面を表示します。削除したユーザーの保存パスワードもKeychainから取り除きます。
- 学籍番号を変更すると、保存パスワードを新しい番号へ引き継ぎます。保存に失敗した場合は元の認証情報に戻します。
- 削除・番号変更後は選択状態と授業情報を更新し、変更前の情報で出席登録しないようにしました。デモでは設定とKeychainを変更しません。

## 利用者の操作

- `att update` で更新し、画面を開き直してください。
- `U`でユーザー管理を開き、対象を選んで `I` で学籍番号を変更、`X` で削除できます。削除の確認画面はキャンセルが初期選択です。
- 既定ユーザーを削除すると残った一覧の先頭が既定になります。最後のユーザーを削除した場合は `A` で新しいユーザーを追加できます。
- 起動中の別画面には、再起動後に変更が反映されます。大学側のアカウントや学籍番号を変更する機能ではありません。
