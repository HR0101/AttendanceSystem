# v0.3.2

## 変更内容
- Homebrew Formula で Playwright の wheel を CPU アーキテクチャ別（Apple Silicon は `macosx_11_0_arm64`，Intel Mac は `macosx_10_13_x86_64`）に切り替えるようにしました。これまでの `universal2` wheel は同梱の Node.js が x86_64 版のみで，Apple Silicon では Rosetta 2 がないと Playwright が起動できず，`brew audit` でも非ネイティブバイナリとして検出されていました。
- リリース時に `HR0101/homebrew-tap` の Formula を自動更新する処理で，`git push` の認証に失敗する問題を修正しました（`gh` の認証情報を push にも使うようにしました）。
- 予定登録の教室番号欄で全角数字を入力すると半角に変換し，入力エラーの案内にも半角・全角の両方が使えることを明記しました。

## 利用者の操作
- Homebrew で導入している場合は `brew update && brew upgrade attendance` を実行してください。
- `git clone` / GitHub ダウンロード版をご利用の場合は，これまでどおり自動更新または `att update` を利用できます。
- 予定登録では教室番号を全角のまま入力できます（例：`６４２`，`７３０１`）。
