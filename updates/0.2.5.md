# v0.2.5

## 変更内容

- ユーザー追加・パスワード変更の入力画面で、F2によるパスワードの表示・非表示を追加しました。開くたびに非表示から始まり、閉じる・送信する際に入力と表示状態を消去します。
- GUIで選択した複数ユーザーを保存し、次回の画面起動時に復元します。削除・学籍番号変更にも保存済みの選択を追従させます。
- ユーザー情報・QR番号・授業予定・期間などの入力欄で、カーソル位置への挿入と削除に対応しました。長い入力もカーソル周辺へスクロールします。

## 利用者の操作

- `att update` で更新して画面を開き直してください。
- パスワードを確認する時は入力画面で `F2`（Macでは必要に応じて `Fn + F2`）を押してください。もう一度押すと隠せます。
- `U`でユーザーをSpaceで選び、Enterで保存します。Escで取り消した選択やデモでの変更は保存しません。通常のコマンド・自動出席には引き続き既定ユーザーを使います。`--user`で指定した場合はその起動だけ指定ユーザーを優先します。
- 入力欄では `←/→` で移動、`Home/End` または `Ctrl+A/Ctrl+E` で先頭・末尾へ移動できます。Backspaceは直前、Deleteはカーソル位置の文字を削除します。`Ctrl+U`で入力全体を消去できます。
