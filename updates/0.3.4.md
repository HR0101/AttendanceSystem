# v0.3.4

## 変更内容
- コントリビューター向けに、[CONTRIBUTING.md](CONTRIBUTING.md) と Pull Request テンプレートの開発・バージョニングルールを拡充しました。
- PR 作成・更新時に最新リリースタグ（`vX.Y.Z`）からのバージョン引き上げ、`Formula/attendance.rb` との同期、更新ノートの記載を自動検証し、PR コメントおよび Job Summary へ結果を通知する CI と PR Version Bot（`.github/workflows/pr-version-bot.yml`）を追加しました。

## 利用者の操作
- 開発・コントリビューション向けのルールと CI の追加のみであり、アプリ本体の動作や日常の利用手順に変更はありません。
- 更新したい場合はこれまでどおり自動更新、`att update`、または `brew update && brew upgrade attendance` を利用できます。
