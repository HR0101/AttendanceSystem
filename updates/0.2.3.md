# v0.2.3

## 変更内容

- 通常起動時は新しいバージョンの有無だけを確認し、更新がある場合にコマンドを案内します。アプリ本体を勝手に更新することはありません。
- `att update --notes` で更新内容を確認できるようになりました。
- 画面モードでも更新通知とコマンドを表示し、画面の再描画後も確認できるようになりました。
- `att update` の実行時に、必要な依存パッケージとChromiumを別の環境へ自動で準備します。準備の失敗時は旧版を保持し、ロールバックでは依存環境も戻します。
- GitHubへの通常のアクセス拒否と利用制限を区別し、制限の解除時刻を表示します。ETagによる更新情報の再利用と、配布先のHTTPS検証も追加しました。

## 利用者の操作

- 更新通知が出たら `att update --notes` で内容を確認し、更新したい時に `att update` を実行してください。
- v0.2.2から移行した後の最初の `att update` では、依存パッケージとChromiumをダウンロードします。インターネットに接続してお待ちください。通常起動は既存の環境で利用できます。
- 問題が起きた場合は `att update --rollback` で直前の版に戻せます。個人設定と元の `.venv` は保持します。
