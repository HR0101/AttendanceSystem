# 出席ツール

macOS 上で本人が受講している授業の出席登録画面を操作します。大学・授業の規則で自動化が許可されている場合に利用してください。追加認証や画面変更があれば停止します。

## コマンドで使う

ターミナルから `att 642` のように教室番号を指定します。このMacでは、どのフォルダからでも実行できます。`att --check 642` は出席ボタンを押さずに状態だけ確認します。教室番号を省略すると入力を求めます。従来の `attendance 642` も使えます。

別のMacでは、セットアップ後にツールのフォルダで `./att 642` と実行できます。どのフォルダからでも `att 642` と呼びたい場合は、`att` をPATHに含まれるフォルダへシンボリックリンクしてください。リンク先のツールフォルダは移動しないでください。

## セットアップ

1. ターミナルでこのフォルダに移動します。
2. `python3 -m venv .venv`、`.venv/bin/python -m pip install -r requirements.txt`、`.venv/bin/python -m playwright install chromium` を実行します。
3. `chmod +x start.command` を実行し、`start.command` をダブルクリックします。
4. 毎回、教室番号を半角数字3桁で入力します（例: `642`、`731`）。初回のみ学生番号とパスワードもターミナルで入力します。

教室番号 `642` は `/attendance/class_room/642` に、7号館の `731` は `/attendance/class_room/7301` に変換します。7号館は3桁目の前に `0` を入れる規則として扱います。

パスワードは macOS Keychain の `UniversityAttendanceTool` に保存します。`student_id` は `config.json` に保存します。学生番号を変更した場合、旧番号の Keychain 項目は必要に応じて手動で削除してください。

現在の `config.json` は `dry_run: false` です。対象授業と履修状態を確認し、出席登録可能な場合は登録ボタンを押します。確認のみで試す場合は `true` に変更してください。`headless` は初期状態で `true` で、ブラウザのウインドウは表示されません。画面を見ながら確認したいときだけ `false` に変更してください。

提示されたログイン画面と出席画面はホスト名が異なります。教室URLは `login_url` と同じホストに作ります。大学側でURLが変更された場合は、公式画面を確認して設定を更新してください。

画面の教室番号が入力と一致しない、出席済みの表示が確認できない、登録前後で授業情報が変わった場合は失敗として停止します。履修未登録の警告が出た場合は出席ボタンを押さずに「履修登録なし（出席操作なし）」と記録します。「現在、出席できる授業はありません。」と表示された場合は「出席受付対象なし（受付時間外の可能性・出席操作なし）」と記録します。この表示だけでは時間外か授業がないかは断定できません。利用者確認による受付時間は授業開始の前後30分です。すでに出席済み表示がある場合や登録後に警告が現れた場合は、仮登録の可能性をログに明記します。結果はターミナルと `logs/` に表示・記録します。
